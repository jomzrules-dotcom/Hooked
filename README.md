# 🎣 Hooked

A cozy fishing game that runs entirely in the browser — one HTML file, no install.

## Play
Open `index.html` in any modern browser, or play online via GitHub Pages.

On iPhone/iPad: open the page in Safari → Share → **Add to Home Screen** for full-screen play.

## Features
- Hold-and-release casting with Perfect / Good / Bad zones
- Reeling fights with fish personalities, surges and jump prompts
- Two maps: **Lakeside Pond** and **Mountain River** (more coming)
- Fish journal, collection rewards, rods, bait, levels and XP
- Character creator (boy/girl, skin, hair, hats, jackets)
- Day/night cycle, weather-like wind gusts, ambient sound and music
- Progress saved on your device
